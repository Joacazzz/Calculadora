Calculadora de Média

Um aplicativo Android projetado para executar a tarefa hercúlea de somar quatro notas e dividir o resultado por quatro. 
Criado sob o altamente criativo pacote com.example.myapplication, afinal, alterar o nome padrão durante a criação do projeto consome um tempo precioso.  🚀

FuncionalidadesMatemática Implacável:
Calcula médias com base em três campos de entrada numéricos.Tolerância a Usuários (e a Vírgulas):
Converte automaticamente vírgulas para pontos antes de processar o cálculo, evitando que o Kotlin sofra um colapso nervoso caso o teclado do usuário esteja em português.Julgamento de Valor: 
Se a média for maior ou igual a 6, o aluno está APROVADO. Caso contrário, REPROVADO. A frieza da máquina não tem piedade.
📂 Estrutura do RepositórioO projeto segue a arquitetura caótica padrão de um aplicativo Android gerado automaticamente:  app/src/main/java/com/example/myapplication/MainActivity.kt:
O cérebro da operação, onde a lógica de validação e o saudoso findViewById residem.  app/src/main/res/layout/activity_main.xml:
A interface do usuário, rigorosamente formatada para não conter espaços proibidos e letais na linha 1, coluna 1.  app/build.gradle.kts: 
O arquivo responsável por fazer o Gradle baixar metade da internet antes de compilar o código.
